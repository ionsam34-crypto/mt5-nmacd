Step 0 · Section 1b
Smart Kill Switch — Design Specification
Per-entry trailing stop armed by 1H pivot structure, executed on the 3M chart.
DESIGN PHASE
⚠
Goal: Protect profit at confirmed structural peaks without closing trades that are in temporary drawdown inside a still-valid 1H regime leg. The kill switch must not interfere with normal strategy operation — it activates only after structural confirmation, not on 3M noise.
Per-Position State Machine
State 0
DISARMED
Default on entry. Kill switch cannot fire. Normal trade management applies (NMACD exit signal, manual close).
Arm → BUY: 1H bar closes above prior confirmed swing HH. SELL: 1H bar closes below prior confirmed swing LL.
State 1
ARMED
Arm reference = confirmed HH (buy) or LL (sell). Trigger price = arm_price − (leg × threshold%). Per-entry: each stack position carries its own trigger.
Fire → BUY: bid < trigger. SELL: ask > trigger. Scope: only fires if trade ever reached profit above entry.
State 2
FIRED
Position closed. Event logged: entry / arm / trigger / close / PnL. No re-entry on same swing leg — wait for new NMACD signal.
Reset → DISARMED (position closed, state cleared).

Step 0 · Section 5
Position Sizing
Owner decision — Codex presents options, does not select.
OWNER DECISION
Fixed Lot
Same lot size every trade regardless of equity. Risk per trade is predictable and does not compound. Drawdown in absolute $ is bounded by the fixed size.
Proportional to Equity
Lot size = f(current equity). Compounds gains and losses. Drawdown % stays relatively stable but absolute $ swings grow as account grows. Captures compound growth.
